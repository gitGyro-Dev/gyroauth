# Business Activity Logs

Use this directory for public-safe records of commercialization and PoC activity.

## Recommended Log Types

- market and use-case evaluations;
- problem-discovery interview summaries;
- public event or program research;
- AUBA and ResearchHub activity;
- demo feedback;
- PoC design decisions;
- critical reviews and adoption objections;
- decisions returned to Gyro Project Cycle;
- technical questions returned to GyroAuth, GyroOS, or Gyro Logic workstreams.

## Naming

```text
YYYY-MM-DD_topic.md
```

Example:

```text
2026-07-31_business_workspace_initialization.md
```

## Log Boundary

Do not record confidential counterpart names, personal information, customer data, private pricing, credentials, or NDA-controlled details in this public directory.

## Recommended Structure

```text
# Title

## Purpose
## Facts and Inputs
## Evaluation
## Criticism / Risks
## Decisions
## Open Questions
## Next Actions
## Project Cycle Reflection
```

Distinguish facts, external feedback, hypotheses, and decisions explicitly.
