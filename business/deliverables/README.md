# Business Deliverables

This directory tracks reusable, public-safe materials for external explanation and PoC preparation.

## Priority A — Entry Materials

- one-page technical overview;
- company-facing explanation deck;
- PoC proposal;
- PoC scope and exclusions;
- required-data list;
- evaluation metrics;
- FAQ;
- comparison with alternative technologies;
- public demo improvement plan;
- contact and inquiry path;
- Japanese and English summaries.

## Priority B — Before a PoC

- data-handling policy;
- security architecture overview;
- offline and Shadow Mode architecture diagrams;
- CSV and JSON schemas;
- sample logs;
- evaluation-report template;
- limitations and non-guarantees;
- responsibility boundary;
- schedule and cost-estimation approach.

## Priority C — After a PoC

- result report;
- decision comparison;
- false-positive and missed-event analysis;
- operator workload analysis;
- implementation and operating-cost estimate;
- productionization gap list;
- runbook and support-policy candidates;
- contract or licensing model candidates.

## Public / Restricted Boundary

Only reusable and public-safe materials belong here. Customer-specific, confidential, contractual, or personal-data materials require controlled storage outside this public repository.

## Artifact Status

Each deliverable should identify:

- status: idea, draft, review, approved, superseded;
- intended audience;
- language;
- source technical artifacts;
- evidence class;
- last review date;
- known limitations.
